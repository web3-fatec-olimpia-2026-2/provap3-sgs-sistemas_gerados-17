# ILP-037 — Laboratório da Aula 05 · Strategy

Você vai refatorar um `if/elif` de tarifa para o padrão **Strategy**, mantendo os testes verdes, e depois acrescentar um tipo novo sem tocar na classe `Reserva`.

## Comece por aqui
1. Abra o **ROTEIRO.md** e siga.
2. Rode os testes com `python3 -m pytest tests/ -v`.
3. Início: 3 verdes (o código já funciona — o problema é o design). Fim: 4 verdes (com a tarifa nova).

## O que é diferente neste lab
O código NÃO está quebrado no começo. Você melhora o design sem mudar o comportamento — isso é refatorar. Os testes são a rede de segurança que prova que você não quebrou nada.

## Python puro — não é Django
Exemplos do professor. A ponte com o projeto vem pelo homework.

## Se der ModuleNotFoundError
Use `python3 -m pytest` (com o -m). O `pytest.ini` já resolve o resto.
