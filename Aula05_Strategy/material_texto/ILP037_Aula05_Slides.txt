===== Página 5 =====
O smell
Um cálculo que incha a cada tipo novo
class Reserva :
def total ( self ) :
base = self . diarias * self . v a l o r _ d i a r i a
if self . t i p o _ h o s p e d e == " comum " :
return base
elif self . t i p o _ h o s p e d e == " f i d e l i d a d e " :
return base * 0.90
elif self . t i p o _ h o s p e d e == " pa rce ir o " :
return base * 0.80
# cada co nve ni o novo = mais um elif AQUI dentro
▲ cada tipo novo obriga a abrir a Reserva e mexer no total()
O código funciona. O problema é o design: ele não está fechado para modificação.

Strategy: cada política, uma classe
O padrão
class T a r i f a C o m u m :
def aplicar ( self , base ) : return base
class T a r i f a F i d e l i d a d e :
def aplicar ( self , base ) : return base * 0.90
class T a r i f a P a r c e i r o :
def aplicar ( self , base ) : return base * 0.80
class Reserva :
def __i ni t__ ( self , diarias , valor_diaria , tarifa ) :
self . tarifa = tarifa # recebe a E S T R A T E G I A
def total ( self ) :
base = self . diarias * self . v a l o r _ d i a r i a
return self . tarifa . aplicar ( base ) # delega - sem if
STRATEGY (GOF)
Uma família de algoritmos, cada um numa classe, intercambiáveis. O objeto recebe uma
estratégia e delega.

O ganho, e o limite
Quando usar — e quando é exagero
Aberto ao novo
Uma tarifa nova = uma classe nova
A Reserva não muda
Aberto para estender, fechado para modificar
Quando NÃO usar
Um comportamento só, que nunca varia
Aí três classes são cerimônia
Em Python, pode ser só uma função
Strategy cabe quando a família VARIA. Sem variação, é fachada.

===== Página 10 =====
Laboratório — refatorar com rede de segurança
45 minutos, Python puro
1. Você recebe a Reserva com o if/elif — e 3 testes que já passam
2. Refatora para Strategy, mantendo os 3 testes verdes o tempo todo
3. Acrescenta uma tarifa nova (VIP) sem tocar na Reserva
A regra da refatoração
Os testes são a rede de segurança. Eles fixam o comportamento. Refatorar é mudar a forma sem
mudar o resultado: 400, 360, 320 continuam iguais. Se um teste fica vermelho, você quebrou algo —
volte.
python3 -m pytest . Regra do Interlocutor: leia o erro em voz alta antes de me chamar.

Fechar o Marco 1
Entrega 11/09 — consolidar, não começar
O Marco 1 avalia a decisão de design da equipe: o Caderno de Design, com os ADRs que vocês já
vêm escrevendo. Fechar é consolidar o que existe.
O QUE A BANCA OLHA
ADRs preenchidos (as cinco seções) • decisões que justificam, não só descrevem •
commits rastreáveis • defesa oral sem consulta.
O erro que custa nota: DESCREVER ("usamos @property") em vez de JUSTIFICAR
("escolhemos @property em vez de validar na tela, porque...").
