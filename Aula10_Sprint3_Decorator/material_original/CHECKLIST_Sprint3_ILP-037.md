## 1. 🛠️ Produto — terminar e estabilizar

*O que foi à Feira é a base. Aqui é fechar o pendente e deixar rodando.*

- [ ] Funcionalidades que faltaram para a Feira **concluídas**
- [ ] Bugs conhecidos **corrigidos** — ou registrados como dívida técnica (uma lista em `/docs/`)
- [ ] O projeto **roda do zero** seguindo o `README` (venv, `pip install -r requirements.txt`, migrações, `runserver`)
- [ ] `README` atualizado com os passos de instalação e execução
- [ ] Repositório **organizado**: sem arquivos mortos, sem `.venv`/`__pycache__` versionados (`.gitignore` ok)
- [ ] Últimos commits com mensagens que explicam o que mudou

---

## 2. 📓 Caderno de Design — `/docs/design/` **(P1 — peça central)**

*Um ADR por padrão do semestre. "Aplicamos" ou "Não aplicamos" — sempre com justificativa.*

- [ ] **ADR — Strategy** (aplicar-ou-não, justificado)
- [ ] **ADR — SRP / OCP**
- [ ] **ADR — MVVM**
- [ ] **ADR — Adapter**
- [ ] **ADR — Facade**
- [ ] **ADR — Decorator** ← fecha o catálogo
- [ ] Cada ADR tem: **Contexto · Decisão · Justificativa · Consequências**
- [ ] As justificativas **explicam** (não só descrevem) — amarradas ao problema real do projeto e à delimitação em Python
- [ ] Commits do projeto rastreáveis a partir dos ADRs (dá para achar onde o padrão foi aplicado)

> Lembrete do semestre inteiro: **a competência avaliada é decidir se o padrão cabe.** Um
> "não aplicamos porque..." bem argumentado vale tanto quanto um "aplicamos porque...".

---

## 3. 🎤 Preparação para a P3 — Prova Prática individual (27/11)

*A P3 é individual. Cada integrante defende o próprio código. Preparem-se um a um.*

Para **cada integrante** da equipe:
- [ ] Sei explicar, em voz alta, o **trecho de código que eu escrevi**
- [ ] Sei dizer **qual padrão** aparece no meu trecho — e **por que** (ou por que **não** usei nenhum)
- [ ] Sei diferenciar os padrões próximos que caíram nos homeworks:
  - [ ] **Adapter × Facade** (traduzir uma peça × esconder vários subsistemas)
  - [ ] **Decorator × Adapter** (manter a interface e empilhar × mudar a interface)
  - [ ] **Service × ViewModel** (regra de negócio × lógica de exibição)
- [ ] Revisei meus **homeworks individuais** do semestre
