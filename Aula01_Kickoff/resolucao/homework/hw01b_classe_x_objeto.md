# Homework 01b — Classe × objeto, com as minhas palavras

A **classe** é a descrição de um tipo: ela diz quais dados toda entidade daquele tipo guarda
(atributos) e o que ela sabe fazer (métodos) — e existe uma única vez, no código-fonte.
O **objeto** é uma entidade concreta criada a partir da classe durante a execução do programa,
com os seus próprios valores para esses dados.
Por isso, de uma classe `Bicicleta` posso criar vários objetos (a minha e a do meu irmão),
e pedalar uma não muda a velocidade da outra: o estado é de cada objeto, não da classe.
É como a planta de um apartamento (classe) e cada apartamento construído a partir dela (objetos).
