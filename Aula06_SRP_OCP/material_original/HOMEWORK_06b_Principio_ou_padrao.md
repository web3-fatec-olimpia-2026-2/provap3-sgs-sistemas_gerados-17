## A tarefa

Em **três a cinco linhas**, responda com as suas palavras:

> **Qual a diferença entre um princípio de design (como o OCP — Aberto/Fechado) e um padrão de projeto (como o Strategy)? Use o exemplo da política de tarifa que vimos para explicar.**

---

## Para você se situar

- Um **princípio** é uma **diretriz geral** de bom design — o "o quê". O OCP diz: "estenda o comportamento sem modificar o código que já funciona." Vale para o código todo, sempre.
- Um **padrão** é uma **solução concreta e nomeada** para um problema recorrente — um "como". O Strategy é uma forma específica de conseguir o OCP: colocar cada comportamento numa classe trocável.

Em outras palavras: o Strategy é **um jeito** de seguir o OCP. O princípio é a meta; o padrão é uma ferramenta que a atinge. Há outros jeitos de seguir o OCP além do Strategy.

A partir daí, a resposta tem que ser **sua**.
