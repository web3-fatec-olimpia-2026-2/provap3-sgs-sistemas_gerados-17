# ILP-037 — Laboratório da Aula 06 · SRP

Você vai separar uma classe que "faz tudo" em três, cada uma com uma responsabilidade — o Princípio da Responsabilidade Única (SRP).

## Comece por aqui
1. Abra o **ROTEIRO.md** e siga.
2. Rode os testes com `python3 -m pytest tests/ -v`.
3. Início: 1 verde, 1 vermelho. Fim: 2 verdes.

## O que é diferente
O código já funciona no começo. Você melhora o design sem mudar o comportamento — o recibo continua idêntico. Isso é refatorar com segurança.

## Python puro — não é Django
Exemplos do professor. A ponte com o projeto vem pelo homework.

## Se der ModuleNotFoundError
Use `python3 -m pytest` (com o -m). O `pytest.ini` já resolve.

## Uso de IA
Nível 2 — pode usar para destravar, declare trechos acima de 5 linhas, saiba explicar.
