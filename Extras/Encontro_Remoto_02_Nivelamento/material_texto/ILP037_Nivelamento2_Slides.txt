===== Página 5 =====
O JOIN: juntar duas tabelas
O alvo do Lab 1
As reservas estão numa tabela; os quartos, em outra. O quarto_id da reserva aponta para o id do
quarto — é o elo. O JOIN usa esse elo:
SELECT r . hospede , q . numero
FROM reserva r
JOIN quarto q ON r . q u a r t o _ i d = q . id
"Traga o hóspede da reserva e o número do quarto, juntando onde o quarto_id da reserva bate com o
id do quarto."

===== Página 7 =====
O que trava todo mundo: o conflito
E por que ele não é um bug
BRANCH
Uma linha de trabalho paralela. Você mexe nela sem afetar o main , até juntar (merge ).
CONFLITO
Quando duas branches mudam a mesma linha de formas diferentes, o Git não sabe
qual manter — e pede que você decida. Isso não é erro seu; é o Git sendo honesto.
No Lab 2 você CRIA um conflito de propósito e resolve. Depois disso, conflito deixa de
assustar.

Ler as marcas do conflito
Três símbolos, uma decisão
- comum
< < < < < < < HEAD
- p r e s i d e n c i a l <- o que voce tinha no main
=======
- suite <- o que vinha da outra branch
> > > > > > > nova - c a t e g o r i a
RESOLVER
Decida o que fica, e apague as três marcas (< , === , > ). Depois: git add e git
commit . Pronto.
Entre < e === : um lado. Entre === e > : o outro. Você escolhe, ou junta os dois.

===== Página 10 =====
O erro não é seu inimigo
É a coisa mais útil na tela
OS TRÊS PASSOS
Todo erro do Python, por mais assustador, se lê assim:
1. Vá para a última linha — ela diz o que deu errado
2. Ache o arquivo e a linha (o "line N") — é onde deu errado
3. Leia o tipo (NameError, ValueError...) — é a pista do porquê
O meio da mensagem é o caminho que o Python percorreu. Leia de BAIXO para cima: a
última linha primeiro.

A tabela de bolso
Os erros mais comuns, e o que quase sempre são
NameError digitou errado o nome de uma variável
TypeError misturou tipos (texto com número)
ValueError o valor não serve (ex.: int("tres") )
IndexError pediu uma posição que a lista não tem
KeyError pediu uma chave que o dicionário não tem
IndentationError espaços/tabs inconsistentes
ModuleNotFoundError import errado, ou rodou da pasta errada
