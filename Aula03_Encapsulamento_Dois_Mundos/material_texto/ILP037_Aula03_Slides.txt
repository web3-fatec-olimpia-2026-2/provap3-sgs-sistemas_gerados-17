ENCAPSULAMENTO
O objeto protege o próprio dado. Em vez de deixar qualquer código gravar qualquer
coisa, o objeto valida antes.
atributo público qualquer um grava lixo (q.diaria = -30 passa)
@property + setter o objeto valida antes de gravar

Onde a equipe registra por que o código é assim — o ADR. É o artefato que só existe
nesta disciplina.

Os dois lado a lado
O mesmo princípio, duas mãos diferentes
Python puro (aqui) Django model (Web III)
Proteger um valor @property + setter que valida validators=[MinValueValidator(0)]
no campo
Por que assim é a ferramenta da linguagem save() não valida; o validador roda
via ModelForm / full_clean()
@property serve para ler e proteger o atributo só dado calculado (o total )
setter num campo do
model
— quebra formulário, admin e ORM
O mesmo conceito de OO tem duas mãos, conforme onde você está. Saber qual usar onde é o que
separa quem decorou de quem entendeu.

===== Página 17 =====
O problema que herança resolve
Categorias de quarto no Resort
No Resort há quarto comum, suíte, quarto presidencial. Todos são quarto — têm número, diária,
hóspede. Mas a suíte tem sala; o presidencial tem mordomo.
A PERGUNTA
Copiar a classe Quarto inteira três vezes, mudando um detalhe em cada, é desperdício
— e vira manutenção em três lugares. Como escrever “a suíte é um quarto, com um
pouco mais”?
A resposta é herança.

Herança: class Suite(Quarto)
A suíte é-um quarto, e reaproveita
class Quarto :
def __i ni t__ ( self , numero , diaria ) :
self . numero = numero
self . diaria = diaria
class Suite ( Quarto ) : # Suite E - UM Quarto
def __i ni t__ ( self , numero , diaria , te m_s ala ) :
super () . _ _i nit __ ( numero , diaria ) # r e a p r o v e i t a o Quarto
self . t em _sa la = tem _s ala
O QUE super() FAZ
Chama o construtor do Quarto de dentro da Suite . A suíte ganha numero e diaria de
graça, sem copiar código, e só acrescenta o que é dela: tem_sala .
PARA FIXAR A categoria de quarto: a suíte é um quarto, com mais. Não se reescreve o quarto — herda-se.

===== Página 19 =====
É-um ou tem-um?
A distinção que vocês vão usar o semestre todo
É-UM → herança
A suíte é um quarto.
class Suite(Quarto)
Quando o novo tipo é uma variação do original.
TEM-UM → composição
O quarto tem um frigobar.
self.frigobar = Frigobar()
Quando um objeto contém outro, mas não é ele.
O TESTE RÁPIDO
Fale em voz alta: “a suíte é um quarto” — soa certo, é herança. “O quarto é um frigobar”
— soa errado, então é tem-um: composição. O ouvido ajuda mais que a regra.
Hoje é só reconhecer. A gente aprofunda na próxima sexta.
