# ILP-037 — Laboratório da Aula 04 · Polimorfismo

Você vai criar Suíte e Presidencial que herdam de Quarto e **sobrescrevem** os métodos, e ver uma única função tratar os três. Isso é **polimorfismo**.

## Comece por aqui
1. Abra o **ROTEIRO.md** e siga.
2. Rode os testes com `python3 -m pytest tests/ -v`.
3. Início: erro de import (você cria as classes). Fim: 5 verdes.

## Python puro — não é Django
Este lab é em Python puro, nos exemplos do professor. Não é o projeto Django da equipe. O conceito você aplica no projeto pelo homework.

## Se der ModuleNotFoundError
Use `python3 -m pytest` (com o -m). O `pytest.ini` já resolve o resto.
